# 工程英语训练（PWA 手机应用）

每天 30 分钟的英语打卡应用，三块内容：

1. **场景造句**（15 分钟）——每天 AI 自动生成一个贴合你工作的场景，你写 3~5 句英文，AI 帮你检查、给更地道的写法，反复改到没问题。
2. **听力抓关键词**（10 分钟）——每天给你对应的 B站搜索链接，你自己打开去听，抓关键词。
3. **跟读模仿**（10 分钟）——每天一段对话，逐句朗读跟读。

内容每天自动交替：**一天工作主题、一天生活主题**（可在设置里切换为全工作/全生活）。

---

## 一、获取 Anthropic API key（内置 AI 需要，免费）

1. 打开 https://console.anthropic.com/ ，注册/登录。
2. 左侧菜单进入 **API Keys** → 点 **Create Key**，起个名字（比如 `english-app`）。
3. 复制生成的 `sk-ant-...` 开头的 key（只显示一次，注意保存）。
4. 打开应用 →「设置」→ 粘贴到 **API key** 一栏即可。

> key 只保存在你自己的手机本地，不会上传到任何服务器。放心。

## 二、部署到手机（二选一）

### 方式 A：Netlify Drop（最简单，无需写代码）

1. 打开 https://app.netlify.com/drop
2. 把本目录（`english-app` 整个文件夹）**拖进去**，等它上传。
3. 得到一个网址（形如 `https://xxx.netlify.app`），用手机浏览器打开。

### 方式 B：GitHub Pages（你已经用了 GitHub）

1. 在 GitHub 新建一个仓库，比如 `english-app`。
2. 把本目录的文件推上去。
3. 仓库 **Settings → Pages → Source 选 main 分支 / root**，得到网址 `https://你的用户名.github.io/english-app/`。
4. 手机浏览器打开这个网址。

## 三、安装到手机主屏（安卓）

用手机 **Chrome 浏览器**打开上面的网址，然后：

- 打开右上角菜单（⋮）→ **添加到主屏幕**（或「安装应用」）。
- 之后主屏幕上就有图标，点开就是全屏，跟 App 一样。

> 必须用 **https** 网址才能安装（上面的方式都是 https）。

## 四、每天怎么用

- 打开 App，点「今日」→「生成今日内容」（第一次或每天首次打开会自动生成）。
- 到点打开 App，顶部会提示你该做哪一块。
- 三块都点「完成」后，今日任务全部打勾。

## 五、常见问题

- **AI 检查/生成报错**：先确认「设置」里 key 已填、没填错；再确认手机能联网。
- **想换成别的模型**：设置 → AI 模型，可选 Opus / Sonnet / Haiku（Haiku 最快最便宜）。
- **换手机或清缓存会丢记录**：数据存在手机浏览器本地，卸载/清缓存会清空，重要记录建议偶尔备份。
